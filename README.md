# MERN Blog

Full CRUD blog: Express/Mongoose API in `backend/`, React (Vite) client in `frontend/`.

1. `cp backend/.env.example backend/.env` and set `MONGO_URI`
2. `cp frontend/.env.example frontend/.env`
3. `npm install && npm run install:all && npm run dev`

See the setup and deployment guide in the chat for Atlas, Render and Vercel steps.
